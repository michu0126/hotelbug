# 采集通道与简化页面

## 按官网实际契约分流

| 范围 | 通道 |
| --- | --- |
| 万豪英文站单房单晚现金房型报价 | 已观察的 `PhoenixBookDTTSearchProductsByProperty` 官网接口 |
| 万豪中文站房型、目录与月历 | 现有 Cookie 浏览器采集，不猜测中文 API |
| IHG、希尔顿、凯悦、雅高、GHA | Cookie 浏览器采集，沿官网正常预订页面读取 |

万豪接口通过独立项目浏览器的 request context 调用，与浏览器共用导入 Cookie 和
代理，不复制 Cookie 到请求头。每个任务创建页面时应用最新连接修订，作用域、
过期、HttpOnly 按浏览器 Cookie jar 保留。目录发现、全年调度和中文月历继续工作。
有公开合作 API 文档不等于本项目具备生产权限，未将这些接口冒充匿名可用接口。

接口契约与字段解析有离线测试；当前 NAS 的真实接口报价仍待验证。
401/跳转提示刷新会话；403/429交由原队列暂停处理，不切域名或重复重试。
空白、错误、积分和分页不完整的响应不会成为零价格或有效现金报价。
Cookie 浏览器分支复用已部署的私有 Cookie 连接，不要求重新填写或清空会话。

## 页面

- 采集概览：四项统计、六集团状态/采集方式/真实覆盖率、降价事件。
- 价格日历：搜索、月历、关注、历史价格。
- 降价通知：Telegram 设置及事件。
- 设置：单一管理令牌、官网 Cookie；高级采集参数与诊断默认折叠。

已有酒店、价格历史、监控范围、通知配置和私有 Cookie 不迁移、不删除。
