# 万豪中国站自动查价验收（2026-10-21）

运行地点：用户 Windows 电脑。本机 Chrome，独立持久化 profile `collector/.profiles/marriott-passive`，本机调试端口 9222。
本轮没有修改群晖、关闭 Container Manager、复制登录凭据或发布镜像。

## 真实查询

酒店：西安钟楼福朋喜来登酒店（XIYBP）。一间房、一位成人、一晚，现金房价。
程序从中国站首页进入酒店介绍页，通过日期控件和“查看房价”触发官网自己的查询。
响应由独立监听器脱敏保存，自动运行器核对新事件、完整报价和 SQLite 入库后确认完成。

| 入住 → 退房 | 独立报价数 | 公开价最低含税费总价 | 会员价最低含税费总价 |
| --- | ---: | ---: | ---: |
| 2026-10-22 → 10-23 | 1 | CNY 968.00 | 此次未取得会员报价 |
| 2026-10-23 → 10-24 | 16 | CNY 668.00 | CNY 634.30 |
| 2026-10-24 → 10-25 | 15 | CNY 698.00 | CNY 663.45 |

合计 32 条新报价。以上是当时响应里的报价，不保证之后仍有库存或价格不变。
这些入住日不构成多个历史采集日，不能把它们当成同一入住日的历史基准。
原始脱敏捕获文件在本地 `captures/marriott/`，没有加入 Git。

10 月 21–22 日官网显示售罄，最初版本误记为等待响应超时；修复后可从匹配的跳转日期和酒店卡片正确识别。
真实页面的外层列表和酒店卡片使用同名 CSS class，已修正选择器只选最内层卡片，避免重复匹配。

## 已完成的运行能力

- 配置清单 × 滚动 365 天；同品牌串行，随机间隔，定期复查。
- SQLite 任务租约、断点续跑、有限重试退避、暂停状态持久保存。
- 独立二次确认优先；已经执行的确认不会反复占用队列。
- 未开放日期保留任务，售罄单独记录，都不伪造零元价格。
- 403/验证码/429 停止；监听器退出时停止页面操作。
- 自动管理自己创建的中间标签页，保留最新结果及用户原有标签页。
- `--status` 查看状态，`--stop` 安全停止，不关闭 Chrome。

## 尚未完成的范围

当前自动酒店清单只有 XIYBP；不能把全年排队数当作已经得到全年实价，也不能称为全球全量接入。
此新流程仅适配万豪中国站，其他集团仍需分别验证页面流程。
通知渠道为 console 演练，尚未做真实 Bark/Telegram 投递；阈值、历史和确认测试使用本地测试数据。
这是本机 collector 子项目，尚未发布或替换 NAS 容器。
